
## คู่มือการใช้งานบนเว็บ (User Manual on Web)

- เปิดที่ `/manual/index.php` (ต้อง Login) หรือคลิกเมนู "คู่มือการใช้งาน" ที่ Sidebar ของระบบ
- เนื้อหาเก็บเป็นข้อมูลใน `manual/data/pages.json` (แยกจาก Layout) — แก้ไข/เพิ่มหน้าได้โดยแก้ไฟล์นี้ ไม่ต้องสร้าง table ใหม่
- ภาพหน้าจอจริงอยู่ที่ `manual/assets/img/<module>/`
- ค้นหาได้ที่ `manual/search.php` (ชื่อเมนู, รหัสหน้าจอ, Field, ข้อความ Validation)
